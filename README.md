# Opn-Link

Opn-Link relie le centre de formation, les formateurs et les apprenants
d'une classe. On y fait l'appel, on y signe les documents, le centre et les
formateurs y passent leurs annonces et leurs supports de cours, chaque
apprenant peut leur écrire en privé, et les formateurs voient où en est
chacun dans sa recherche de stage ou d'alternance. L'app est libre, gratuite,
et marche sans serveur à payer.

Rien n'est codé pour l'instant. Le cadrage est fini : toutes les questions de
produit sont tranchées. Le concept, la navigation et les maquettes sont
validés, et les règles aussi.

- [docs/projet.md](docs/projet.md) : ce que fait l'app, et ce que contient la
  première version
- [docs/brief-conception.md](docs/brief-conception.md) : tout ce qu'il faut
  savoir pour concevoir l'app, son design et sa navigation
- [docs/conception.md](docs/conception.md) : le concept, « la réponse
  d'abord », et la navigation de chaque interface
- [maquettes/](maquettes/) : les 71 écrans validés, en HTML
- [docs/regles.md](docs/regles.md) : les règles d'Opn-Link, chacune avec la
  façon de la vérifier
- [docs/ux.md](docs/ux.md) : les exigences d'UX et de design, et ce que font
  les concurrents
- [docs/architecture.md](docs/architecture.md) : une app en Rust qui marche
  aussi sur le web
- [docs/prototype.md](docs/prototype.md) : la prochaine étape, le prototype
  de l'appel, qui attend le feu vert du mainteneur
- [docs/mesures.md](docs/mesures.md) : les relais, les fichiers, l'horodatage,
  le poids du site, les QR et les PDF, mesurés avant les maquettes (les sondes
  sont dans [mesures/](mesures/))
- [docs/questions-ouvertes.md](docs/questions-ouvertes.md) : ce qui reste à
  décider
- [docs/carnet.md](docs/carnet.md) : les décisions prises, avec leur date
- [docs/recherche/](docs/recherche/) : les recherches faites avant de
  commencer, et celle sur les usagers et leurs écrans

Opn-Link utilise le même matériel de design
qu'[OpenContact](https://github.com/mahi010110/Open-Contact), l'app de suivi
de la recherche de stage : le style « Utilitaire 98 ». Ses écrans, sa
navigation et son UX sont pensés pour lui, pour les apprenants, les
formateurs, le centre et les tuteurs, et pour leurs différents écrans.
